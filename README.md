# TraceBoard

Доска расследований для Windows на C# / .NET 8 / Windows Forms.
Монохромный интерфейс, Montserrat и свободное расположение карточек.

## Запуск

Откройте `TraceBoard.exe` из папки `TraceBoard-Windows`.
Версия для Windows x64 содержит .NET Runtime: отдельно устанавливать .NET не нужно.
При переносе скопируйте всю папку программы, включая `Assets` и библиотеки.
Если скачали ZIP, сначала распакуйте его целиком.

Приложение открывает учебное дело «Последний сеанс» с вымышленными персонажами
и событиями. Для своей доски нажмите **Новое**.

## Возможности

- Карточки четырёх типов: персона, улика, место и заметка.
- Название, описание и фотография в каждой карточке.
- Перетаскивание карточек и перемещение по доске.
- Связи между карточками с редактируемыми подписями.
- Масштабирование колесом и кнопка «Вся доска».
- Поиск по названиям и описаниям: остальные карточки затемняются.
- Отмена и повтор действий, до 30 шагов с ограничением объёма истории.
- Сохранение в переносимый JSON-файл `.traceboard`, включая фотографии.
- Экспорт всей доски в PNG через меню **Ещё**.
- Локальный черновик для восстановления после незапланированного закрытия.

## Управление

| Действие | Управление |
| --- | --- |
| Добавить карточку | Кнопка «+ Карточка» |
| Добавить заметку на выбранное место | Двойной щелчок по пустой доске |
| Редактировать карточку или связь | Двойной щелчок по ней |
| Переместить карточку | Перетаскивание левой кнопкой |
| Переместить доску | Перетаскивание пустого фона; средняя кнопка; Пробел + мышь |
| Изменить масштаб | Колесо мыши, кнопки − / + |
| Показать всю доску | F или «Вся доска» |
| Соединить карточки | «Связь», затем щёлкнуть две карточки |
| Отменить режим связи | Esc |
| Перейти к результату поиска | Enter в поле поиска |
| Удалить выбранную карточку или связь | Delete |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Сохранить / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Открыть / создать дело | Ctrl+O / Ctrl+N |

Фотографии можно добавлять кнопкой **Фото**, через редактор карточки
или перетаскиванием одного файла из проводника.

## Файлы и ограничения

Сеть и облачный сервис не используются. Файл дела сохраняется в выбранную вами
папку. По умолчанию диалог сохранения открывается в папке приложения на диске D:.
Черновик находится рядом с программой: `Data/Recovery.traceboard`.
Папка программы должна быть доступна для записи. При обычном закрытии приложение
предложит сохранить изменения; отказ от сохранения удаляет черновик.
Не запускайте несколько экземпляров из одной папки: у них общий файл черновика.

До 500 карточек и 2000 связей на доске; открываемый файл — до 100 МБ.
Фото: PNG, JPEG, BMP или GIF до 20 МБ и до 12 000 пикселей по стороне.
При добавлении фото преобразуется в JPEG с длинной стороной до 1600 пикселей;
GIF сохраняется как неподвижное изображение. Оригинальные файлы не изменяются.
PNG-экспорт ограничен 5000 пикселями по каждой стороне.

## Сборка исходников

Нужен .NET 8 SDK на Windows. Откройте `TraceBoard.csproj` в Visual Studio
с компонентом разработки классических приложений .NET либо выполните:

```powershell
.\build.ps1
```

Скрипт использует SDK из `D:\Codex\tools\dotnet`, если он там установлен,
или `dotnet` из PATH. Кэш и временные файлы размещаются на D:.
Результат: соседняя папка `TraceBoard-Windows`.

## Структура

- `MainForm.cs` — главное окно, команды, файловые операции и черновики.
- `BoardCanvas.cs` — отрисовка доски, мышь, масштаб, связи и экспорт.
- `Models.cs` — формат дела, проверка входных данных и история изменений.
- `Dialogs.cs` — редактор карточки, диалоги и импорт фотографий.
- `Theme.cs` — оформление и подключение шрифтов.
- `Assets/Fonts/OFL.txt` — лицензия SIL Open Font License на Montserrat.

Сборка Release для Windows x64 выполнена успешно. Автоматические и интерактивные
тесты не запускались.
